# GM Derken Releases

Versão atual: v14.8

## v14.8 — atualização automática real

- Atualizador local para Windows instalado uma única vez.
- Próximas versões são detectadas automaticamente.
- O ZIP oficial é baixado automaticamente.
- O SHA256 da Release é verificado antes da instalação.
- Um backup local é criado antes de substituir arquivos.
- A extensão recarrega quando uma versão nova já foi instalada.
- O popup mostra o estado do atualizador e as novidades da versão.
- Textos com codificação quebrada foram corrigidos.
- FREE, PRO, licenças e painel ADMIN foram preservados.

### Primeira instalação

A v14.8 é a versão de transição. O Atualizador GM Derken precisa ser
instalado uma única vez. A partir das versões seguintes, não é necessário
baixar outro ZIP manualmente.

Nenhuma senha, cookie do Facebook, ADMIN_TOKEN ou chave privada é coletada.
